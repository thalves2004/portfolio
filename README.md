## 📂 Projetos em destaque

### 🍽️ Sistema de Gestão para Pastelaria

Sistema desenvolvido para auxiliar no gerenciamento diário de uma pastelaria.

Principais funcionalidades:

- Abertura e fechamento de caixa
- Controle de produção
- Controle de estoque
- Registro de perdas
- Controle de pagamentos
- Relatórios por período
- Diferentes níveis de acesso
- Aplicação instalável como PWA

Tecnologias utilizadas:

`Python` `Flask` `PostgreSQL` `HTML` `CSS` `JavaScript`

---

### 🎵 YouTube MP3/MP4 Downloader

Aplicação desenvolvida em Python para download de conteúdos em diferentes formatos.

Principais funcionalidades:

- Download de áudio
- Download de vídeo
- Download de playlists
- Escolha da qualidade
- Conversão utilizando FFmpeg

Tecnologias utilizadas:

`Python` `yt-dlp` `FFmpeg` `PyInstaller`
